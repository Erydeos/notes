

| cd                 |                    |
| ------------------ | ------------------ |
| cd                 | home directory     |
| cd *absolute path* | dir, starts with / |
| cd ./dir           | wd/dir             |
| cd dir             | dir                |
| cd -               | previous wd        |

| clear & reset |                 |
| ------------- | --------------- |
| clear         | clear terminal  |
| reset         | resets terminal |

| ls        |                                  |
| --------- | -------------------------------- |
| ls        | list wd contents                 |
| ls *path* | list dir                         |
| ls -a     | include hidden files/directories |
| ls -l     | long format                      |
| ls -d     | list wd                          |
| ls -F     | classify file or dir             |
| ls -i     | show inode number (data point)   |

| file            |                              |
| --------------- | ---------------------------- |
| file *filename* | description of file contents |

| less            |               |
| --------------- | ------------- |
| less *filename* | read contents |
| q               | to exit less  |

| Files       |             |
| ----------- | ----------- |
| .*filename* | hidden file |
|             |             |
